# Sweet Cravings

A polished bakery-themed landing page for a fictional boutique bakery brand, built as a lightweight Node/Express site.

## Features
- Warm, modern bakery storefront design
- Hero section, menu, story, reviews, and contact form
- Responsive layout for desktop and mobile
- Inviting call-to-action for custom cake orders

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000
